PV String Sizing & Voltage Calculator

Cold-weather Voc and hot-weather Vmp, checked against your inverter's window
Solar Index SO.01 Sizing Tools SO.05 String Sizing SO.02 Notes
Module voltage rises in cold weather and falls in hot weather. A string sized only at STC (25°C) can exceed the inverter's max input voltage on a cold clear morning, or sag out of the MPPT window on a hot afternoon. Enter your module datasheet values and site temperature extremes to check a candidate string length on both ends.
1

Module Electrical Specs (from datasheet, at STC)

STC = Standard Test Conditions, 25°C cell temperature, 1000 W/m² irradiance.
2

Site Temperature Extremes

Use the ASHRAE (or local code) extreme low for the cold case, and the highest expected cell temperature — usually ambient design high plus 25–30°C rise for hot roof-mounted arrays — for the hot case.
3

How this is calculated
Cold Voc: Voc_cold = Voc × (1 + (coeff/100) × (Tmin − 25))  ·  Hot Vmp: Vmp_hot = Vmp × (1 + (coeff/100) × (Tmax − 25))  ·  String voltage: V_string = modules × V_module
This uses the Voc temperature coefficient for both checks as a conservative first pass — some datasheets publish a separate, smaller Vmp coefficient, which gives a slightly less pessimistic hot-string figure. Always leave headroom below the inverter's absolute max voltage; a string right at the limit on a normal cold morning risks nuisance trips or damage on a colder-than-expected day.
