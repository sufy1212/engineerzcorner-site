Grid-Tie vs Off-Grid vs Hybrid Selector

Answer a few questions, get a recommended system type and a full comparison
Solar Index SO.01 Sizing Tools SO.03 System Type Selector SO.02 Notes
Before sizing an array, battery bank or inverter, the first decision is which system architecture fits the site — grid-tied (cheapest, no backup), hybrid (grid-tied with battery backup) or fully off-grid (no utility connection at all). Answer the questions below for a first-pass recommendation, then use the comparison table to sanity-check it against your own priorities.
1

Grid Connection

Whether a utility grid connection is available at the site, and how reliable it is.
If there's no grid at all, the system is off-grid by definition — the rest of the questions just shape battery sizing later.
2

Backup Needs & Economics

How much of the load needs to keep running through an outage, and whether net metering is available.
Batteries are the single biggest cost driver — the more backup or independence needed, the more battery capacity (and cost) the system carries.
