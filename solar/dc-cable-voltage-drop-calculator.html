Voltage drop and minimum cable size for the array-to-battery or array-to-inverter DC run
Solar Index SO.01 Sizing Tools SO.11 DC Cable Sizing SO.02 Notes
DC voltage drop matters more on solar runs than most AC circuits, because a 2–3% loss on a low battery-bank voltage is proportionally much bigger than the same loss on 230V or 400V. Check an existing cable size first, then use Step 2 to find the minimum size for your target drop.
