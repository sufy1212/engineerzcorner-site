How this is calculated
Zk = √(R² + X²) accumulated along each board's own path back to source  ·  Ik'' = c·Un / (√3·Zk)  ·  ip = κ·√2·Ik'',  κ = 1.02 + 0.98·e(−3R/X)
Cable R correction (only when c=0.95): R = [1 + 0.004·(θe−20)]·R20, θe from insulation type.
Motor contribution (if entered): IkM = (ILR/In)·In, added arithmetically to that board's own Ik'' and ip (κM = 1.8).
Method: IEC 60909-0, radial network, algebraic (worst-case) impedance summation. Each board only sums the impedance of the path from source to itself.
Still simplified vs. a full study: source X/R is a typed estimate not a measured value, and motor back-feed only adds to the board the motor sits on, not to boards upstream of it. For contractual/compliance-grade reports, cross-check in SIMARIS or ETAP.
Simplified method for practical LV studies — verify against SIMARIS or a full IEC 60909 study before finalising protection settings on critical boards.
