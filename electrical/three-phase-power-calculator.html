How this is calculated
Three-phase: S = √3 · VLL · I  ·  Single-phase: S = V · I
P = S · cosφ  ·  Q = S · sinφ  ·  φ = cos⁻¹(PF)
Assumes a balanced three-phase load. For an unbalanced load, compute each phase separately using the single-phase formula.

About the Three-Phase Power Calculator

Enter any two of voltage, current, power, and power factor for a three-phase load, and this fills in the rest using the standard three-phase power relationships — the same conversion that comes up constantly when a nameplate gives kW but a spec sheet asks for full-load amps, or vice versa.

It's a straightforward algebraic conversion, not a load study — it doesn't account for harmonics, motor inrush current, or load diversity across a panel or feeder. For actual cable or breaker sizing, use the dedicated Cable Sizing and Short Circuit calculators, which build in the derating and fault-current checks this conversion tool doesn't cover.
