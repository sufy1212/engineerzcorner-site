How this is calculated
Conductor diameter: d (mm) = 0.127 × 92(36 − n)/39, where n is the AWG number (4/0 = −3, 3/0 = −2, 2/0 = −1, 1/0 = 0, then 1, 2, 3…).
Cross-sectional area: A = π/4 × d²
mm² → AWG solves the same formula for n and rounds to the nearest whole AWG size.
The "nearest standard metric size" rounds up to the next size in the common IEC series (0.5, 0.75, 1, 1.5, 2.5, 4, 6, 10, 16, 25, 35, 50, 70, 95, 120, 150, 185, 240, 300, 400, 500 mm²) so the resulting conductor is never smaller than the AWG size it's replacing. Stranded conductors and specific manufacturer catalogues may round differently — check the datasheet for your actual product.
Geometric size conversion only — ampacity, voltage drop and thermal withstand need a separate check.

About AWG and Metric Wire Sizing

American Wire Gauge is a logarithmic sizing standard, so each step down in AWG number is a fixed percentage increase in cross-sectional area rather than a fixed amount — that's why the numbering looks arbitrary next to the mm² sizes used almost everywhere outside North America. This converter runs the standard AWG geometric formula both directions, so you can take a spec written in one system and get a usable equivalent in the other.

The nearest-standard-size result is a starting point for cross-referencing a US-spec drawing against a metric cable catalogue, or vice versa — it doesn't replace checking the actual manufacturer datasheet, since stranding, insulation and conductor material all affect the real-world equivalent between two wires with the same nominal area.
