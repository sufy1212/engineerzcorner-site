About the Cable Schedule Builder

Each row records a cable's tag, its origin and destination, size and core count, length, and type — the fields a cable schedule needs for issue on a drawing set or handover package. Running totals update as you add entries, so you can see total cable length or count by type without tallying manually.

Everything is saved in this browser as you work, and the Export options let you pull the schedule into a spreadsheet as CSV or save a project file to reload later and keep editing. This tool only records what you enter — it doesn't check ampacity, voltage drop, or fault withstand, so pair it with the sizing calculators for those checks before a cable schedule is finalized.
