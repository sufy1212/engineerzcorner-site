How this is calculated
Transformer impedance: Zt = (%Z/100) × VLL² / (SkVA×1000), in Ω.
Bus fault: Ik'' = VLL / (√3 × Zt).
Feeder-end fault: Ik'' = VLL / (√3 × (Zt + Zcable)) — seen by both the main breaker and that feeder's breaker in series.
Trip time zones per breaker: long-time t = tr·(Ir·In/I)² for Ir·In ≤ I < Isd·Ir·In; short-time t = tsd (flat) for Isd·Ir·In ≤ I < Ii·In; instantaneous t ≈ 0 for I ≥ Ii·In.
Selective if the upstream breaker's trip time exceeds the downstream breaker's by at least the minimum margin set above, and the fault stays below the upstream breaker's own Ii pickup.
