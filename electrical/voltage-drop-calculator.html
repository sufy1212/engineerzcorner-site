How this is calculated
Three-phase: ΔV = √3·(R·ΣIp + X·ΣIq)  ·  Single-phase: ΔV = 2·(R·ΣIp + X·ΣIq)
ΣIp, ΣIq = active/reactive current of that board's own load PLUS every board feeding off it downstream — so a cable feeding a sub-board carries that sub-board's current too, not just its own.
%ΔV (this run) = ΔV / Un × 100  ·  Cumulative %ΔV at a board = sum of %ΔV along the path back to source
R, X calculated the same way as the short circuit page (ρ·L/A for R, given Ω/km for X), at 20°C — no fault-temperature correction applies here since this is steady-state loading, not a fault.
Diversity/demand factor isn't applied automatically — enter the actual expected running current per board's own load, not the connected/nameplate total, for a realistic result.
Voltage drop per IEC 60364-5-52 guidance — check your project spec or local code for the applicable limit.
