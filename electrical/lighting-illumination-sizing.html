Lighting / Illumination Sizing

Lumen method — fitting count for a target lux level
Number of luminaires needed to hit a target average illuminance in a room, using the standard lumen method: required lumens are spread across the room area and derated by how much of that light actually lands on the working plane (utilization factor) and how much output is lost to dirt and lamp aging over time (maintenance factor). A quick layout check, not a point-by-point photometric design.

How this is calculated
Total lumens required: F = E × A / (UF × MF)  ·  Number of luminaires: N = F / lumens per fitting, rounded up
This gives an average illuminance and fitting count only — it doesn't check uniformity, glare, fitting spacing/mounting height ratios, or emergency lighting requirements, all of which need a proper photometric layout for a final design.
