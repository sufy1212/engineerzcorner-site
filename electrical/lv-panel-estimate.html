▸ ADVANCED — dimensional & density assumptions (auto-calculated, override if needed)
1.2 A/mm² is a common conservative rule of thumb for air-insulated copper busbar — verify against IEC 61439 temperature-rise data for anything final. Way widths and chamber sizes are typical starting figures, not fixed catalog dimensions.
▸ LIVE COPPER PRICE — optional, needs a free API key
There's no free, keyless public API for copper spot price (unlike exchange rates). Get a free key in under a minute at api-ninjas.com/api/commodityprice, paste it above, then hit the "⟳ Live" button next to Copper busbar rate. The key is saved only in this browser's local storage — never sent anywhere except directly to api-ninjas.com — and this still returns raw COMEX copper metal price, not an assembled/formed busbar price, so treat it as a starting point, not a quote.
