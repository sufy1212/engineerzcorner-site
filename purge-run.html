Purge Run

Take each vessel from air to a safe oxygen level. Pick a method, set the flow, time or pressure cycles, and watch the oxygen curve against the LOC and your target. Use as little nitrogen as you can.

Stars: 0 / 15 5 vessels
  • 1The target sits below the limiting oxygen concentration (LOC): LOC minus 2 points with continuous monitoring, or 60% of LOC without it.
  • 2Dilution: oxygen falls as C = C₀e−ηQt/V, so turnovers N = ln(C₀/C₁) and nitrogen used = Q × t. Pressure swing: each cycle divides oxygen by the pressure ratio.
  • 3Reach the target inside the time limit for two stars. Use within 20% of the least nitrogen for three. Start at 20.9% O₂.

About Purge Run

The game uses the textbook models: perfect-mixing dilution with a mixing-factor allowance for real vessels, and ideal-gas pressure swing. Real purges need measurement at the worst point in the vessel, and the LOC and margins must come from the fuel's data and the standard you work to (NFPA 69 as summarised in the post).

The full explanation is in Vessel Purging and Inerting Explained, and the purge gas sizing calculator does the dilution maths. This is practice, not a procedure for a real vessel.
