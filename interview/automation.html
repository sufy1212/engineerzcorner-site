Instrumentation Fundamentals

The measurement and signal basics that come up constantly.
QuestionAnswer
What's the difference between accuracy and repeatability in an instrument?Accuracy is how close a reading is to the true value; repeatability is how consistent readings are for the same input under the same conditions — an instrument can be repeatable but not accurate if it's consistently offset (needs calibration).
Explain the difference between 4-20mA and 0-10V signals.4-20mA is a current loop signal, largely immune to voltage drop/noise over long cable runs and self-diagnosing (0mA clearly means a fault, not zero reading); 0-10V is simpler but more susceptible to noise and voltage drop over distance.
Why does a 4-20mA signal start at 4mA instead of 0mA?The live zero lets you distinguish a genuine zero reading (4mA) from a broken wire or power loss (0mA), which is a built-in fault-detection feature.
What's the difference between open-loop and closed-loop control?Open-loop control applies a fixed action without checking the result (no feedback); closed-loop control measures the actual output and continuously adjusts the input to correct any deviation from setpoint.
Explain the difference between a transmitter and a transducer.A transducer converts one form of energy/signal to another (e.g., pressure to a small electrical signal); a transmitter takes that signal and conditions/amplifies it into a standardized output (like 4-20mA) suitable for transmission to a controller.
What's the purpose of a control valve's fail-safe position (fail-open/fail-closed)?On loss of signal or air supply, the valve moves to a predetermined safe position (open or closed, set by the actuator's spring/design) so the process defaults to a safe state rather than an unpredictable one.
What's the difference between a two-wire and a four-wire transmitter?A two-wire (loop-powered) transmitter uses the same two wires for both power and the 4-20mA signal, drawing its power from the loop itself; a four-wire transmitter has separate wires for power supply and signal output, needed when the device requires more power than the loop can provide.
What is turndown ratio and why does it matter for instrument/valve selection?It's the ratio between the maximum and minimum flow (or range) an instrument or valve can measure/control accurately; a low turndown ratio means the device may lose accuracy or control quality if the actual process operates well below its maximum design flow.
Explain the difference between HART and Fieldbus communication.HART overlays a digital signal on the standard 4-20mA analog signal, so it's backward compatible with legacy analog systems while adding diagnostics; Fieldbus (e.g., Foundation Fieldbus, Profibus) is a fully digital, multi-drop communication protocol carrying more data per device and typically requiring dedicated infrastructure.
What's the difference between a relative and an absolute pressure measurement?Gauge (relative) pressure is measured relative to atmospheric pressure (zero at atmosphere); absolute pressure is measured relative to a perfect vacuum (zero at true vacuum) — absolute = gauge + atmospheric pressure.
What is a smart positioner and what advantage does it give over a simple pneumatic positioner?A smart (digital) positioner uses a microprocessor to precisely control valve position, offers diagnostics (stiction, travel deviation, response time), and can be configured/calibrated remotely — giving better control accuracy and predictive maintenance insight versus a purely mechanical pneumatic positioner.
What's the difference between intrinsically safe and explosion-proof equipment ratings?Intrinsically safe design limits the energy in the circuit itself so it can never generate a spark/heat capable of igniting a hazardous atmosphere; explosion-proof (flameproof) design instead allows an internal ignition but contains it within a rugged enclosure so it can't ignite the surrounding atmosphere — different philosophies for the same hazard.

Control Systems & PLC

PID, PLC logic and the practical control-engineering questions.
QuestionAnswer
Explain the three terms in PID control.Proportional acts on the current error, Integral eliminates steady-state error by accumulating past error over time, and Derivative reacts to the rate of change of error to dampen overshoot — tuned together to balance speed and stability.
What happens if you increase the integral gain too much?The controller responds more aggressively to accumulated error, which speeds up steady-state error correction but increases the risk of overshoot and oscillation (integral windup can also become a problem if the actuator saturates).
What's the difference between a PLC and a DCS?A PLC is typically used for discrete/sequential control of a machine or process cell with fast scan times; a DCS is architected for large, continuous plant-wide control with distributed processing, more built-in redundancy and process-oriented tools — the line has blurred but the design philosophy differs.
What is a SCADA system used for?Supervisory Control and Data Acquisition — it gathers data from field devices/PLCs/RTUs across a site or wide area, presents it to operators (trends, alarms, mimic screens) and allows supervisory-level control commands.
Explain ladder logic and why it's still widely used in PLCs.A graphical programming language modeled on relay logic (contacts and coils in rungs); it's still common because it maps intuitively to physical relay/switch logic that electricians and technicians already understand, easing troubleshooting.
What is signal scaling and why is it needed?Converting a raw instrument signal (e.g., 4-20mA) into real engineering units (e.g., 0-100°C) using the known range, so the value displayed/used in logic reflects the actual process variable.
What's the difference between a normally open (NO) and normally closed (NC) contact, and why does the choice matter for safety circuits?NO closes only when actuated; NC is closed by default and opens when actuated. Safety circuits typically use NC contacts so that a broken wire or lost power is detected as a fault/stop condition (fail-safe) rather than silently failing as if everything were fine.
What is the difference between an analog and a discrete (digital) I/O point on a PLC?A discrete I/O point represents a simple on/off (binary) state (e.g., a limit switch or a motor start command); an analog I/O point represents a continuously variable value (e.g., 4-20mA from a transmitter or a variable speed command) requiring analog-to-digital or digital-to-analog conversion.
What's the purpose of a safety instrumented system (SIS) and how does it relate to the basic process control system (BPCS)?The BPCS handles normal, everyday process control; the SIS is a separate, independent layer designed specifically to detect hazardous conditions and take the process to a safe state, providing protection even if the BPCS itself fails or misbehaves.
What is cascade control and when would you use it?A control structure where the output of one (master/primary) controller sets the setpoint of another (slave/secondary) controller, which responds faster to disturbances closer to the final control element — used when there's a faster inner process variable (e.g., valve position or flow) that can correct disturbances before they significantly affect the slower primary variable (e.g., temperature).
What is the difference between feedback and feedforward control?Feedback control reacts after an error is measured between setpoint and actual value; feedforward control anticipates a known disturbance and adjusts the output proactively before it affects the process variable — the two are often combined for faster, more stable control.
What does 'bumpless transfer' mean in the context of manual/auto control switching?It means switching between manual and automatic control modes without causing a sudden jump (bump) in the controller output, which could otherwise upset the process — achieved by tracking the output value continuously in the inactive mode so the transition is seamless.

Site & Practical Scenarios

Commissioning, loop-checking and troubleshooting on live systems.
QuestionAnswer
A control loop is oscillating — how would you approach tuning it?Check for an obvious mechanical cause first (valve stiction, sensor noise, sizing issue), then reduce gain until oscillation stops and retune systematically (e.g., Ziegler-Nichols or a similar method) rather than guessing at parameters.
How would you perform a loop check on a new instrument?Simulate or apply a known input at the field device, verify the correct reading appears at the controller/HMI, confirm the output correctly drives the final control element, and check the failure mode is as specified.
A transmitter reads a value that seems too high compared to a local gauge — how do you investigate?Check for calibration drift, wiring/loop resistance issues, whether the transmitter and gauge are actually measuring the same point (elevation/process tap differences), and cross-check with a calibrated reference instrument.
What's your process for troubleshooting a valve that won't reach its commanded position?Check the control signal is actually reaching the positioner, air/hydraulic supply pressure is adequate, the positioner is calibrated to the actuator's stroke, and there's no mechanical obstruction or excessive friction/stiction in the valve itself.
How do you approach commissioning a new automation system safely?Work through a structured sequence — power-up checks, I/O verification, loop checks, interlock/safety function testing, then functional/sequence testing — with sign-off at each stage before moving to live process operation.
What would you check if a PLC output isn't energizing a field device even though the logic shows it's true?Check the physical output module/point (forced value, blown fuse, wiring), field wiring continuity, power to the device, and any interposing relay or safety interlock that might be blocking it downstream of the PLC.
A level transmitter reads erratically in a turbulent vessel — how would you address it?Check whether a stilling well or damping/filtering setting is appropriate for the technology in use, verify mounting location isn't near an inlet/agitator causing turbulence at the sensor, and confirm the damping time constant is tuned to smooth noise without masking real process changes.
How would you approach a PLC program that's been modified on-site without updated documentation?Compare the running program against the last known-good backup/documentation to identify the actual changes, understand why they were made before deciding whether to keep or revert them, and update documentation immediately once resolved so it doesn't happen again.
What's your process for verifying a safety interlock actually works, not just that it's wired?Functionally test it by inducing (or simulating) the actual trip condition and confirming the correct safe-state response occurs end-to-end — visually checking wiring or logic alone doesn't prove the interlock performs as intended in the field.
How would you diagnose intermittent noise/interference on an analog signal loop?Check for improper cable segregation (signal cables run alongside power cables), missing or multiple ground points on shielding (which can create ground loops), and loose terminations — intermittent issues are often connection- or routing-related rather than the instrument itself.
What would you do if a process safety valve (PSV) lifts unexpectedly during normal operation?Treat it as an abnormal event requiring investigation, not just a reset — check for an upstream control failure, blocked outlet, or process upset that caused overpressure, and don't assume the valve itself is faulty until the process cause is ruled out.
How do you approach validating a new automation sequence before it goes live on a running process?Test it in a simulated or offline environment first if possible, review the logic against the functional design/cause-and-effect matrix with operations, and plan a controlled first live run with extra monitoring rather than switching over unmonitored.
