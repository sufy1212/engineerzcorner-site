Estimates the normal venting capacity an atmospheric/low-pressure storage tank needs — separate from the emergency fire-case relief — using the classic, widely-taught simplified API 2000 method: Table 1 (liquid-movement inbreathing/outbreathing) plus a simplified thermal-breathing rule based on tank capacity or surface area. Inbreathing sizes the vacuum-relief side of the vent/PVRV; outbreathing sizes the pressure-relief side. This is a screening-level estimate, not a substitute for the current edition's full method — see the note below the results.

How this is calculated
Qmi = 5.6 × (emptying rate, bbl/hr)  ·  Qmo = (6 or 12) × (filling rate, bbl/hr)
Qti = 1.0×Capacity(bbl) if Capacity ≤ 20,000 bbl, else 2.0×(shell+roof area, ft²)  ·  Qto = 0.6×Qti (high flash pt) or Qti (low flash pt)
This reproduces the simplified, widely-taught API 2000 screening method: Table 1 for liquid-movement venting (5.6 SCFH per bbl/hr emptying at any flash point; 6 SCFH per bbl/hr filling for higher flash point/NBP stocks, 12 SCFH per bbl/hr for lower flash point/NBP stocks), and a simplified thermal-breathing rule (1 SCFH per barrel of capacity for tanks up to 20,000 bbl, 2 SCFH per ft² of shell+roof area above that, with outbreathing reduced to 60% of the inbreathing value for higher flash point/NBP stocks). It does not implement the current (7th) edition's full rigorous thermal method in Annex A, which additionally accounts for site latitude, solar insolation, tank insulation and paint color, vapor pressure of the stored liquid, and produces different — often lower — thermal requirements for a specific site. It also does not cover emergency (fire-case) venting, which is sized separately from wetted surface area per API 2000 Section on emergency venting and can far exceed the normal venting values shown here. Use this for early sizing/screening only; final PVRV and vent-pipe selection should follow the complete current-edition calculation for the actual site and product.
