Checks actual pipe velocity against the API RP 14E erosional velocity guideline — a widely used rule-of-thumb ceiling for erosion/corrosion risk in single- and two-phase process lines. It's a screening check, not a full erosion/corrosion study — solids content, CO₂/H₂S service and elbow geometry can all lower the practical limit further.

How this is calculated
—
Ve = C/√ρ (ft/s, ρ in lb/ft³) — the API RP 14E erosional velocity guideline. Actual velocity v = Q/A, with Q = W/ρ (volumetric flow) and A the pipe's internal cross-sectional area.
