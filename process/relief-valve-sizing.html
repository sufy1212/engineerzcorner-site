Relief Valve (PSV) Sizing

Required orifice area — API 520 simplified, liquid or vapor service
Process Index PR.01 Relief Valve Sizing PR.02 Vessel Volume/Level PR.03 Line Sizing (Erosional V) PR.04 Cavitation/Flashing PR.05 Purge Gas Sizing PR.10 Heat Exchanger (LMTD) PR.11 Pipe Wall Thickness PR.12 NPSH Available PR.06 Notes PR.07 Symbols PR.08 Guides PR.09 Comparisons
A simplified, preliminary sizing check against the API 520 liquid and vapor/gas equations — useful for a first-pass orifice estimate. It doesn't replace a full sizing calculation (two-phase relief, fire case heat input, rupture disk combination capacity factors, or manufacturer-certified Kd) — take a final selection to the valve manufacturer's sizing software or a full API 520 calculation.

Service & Set Conditions

10% for a single valve on fire/process overpressure; some codes allow 16% or 21% for fire case only.
Used only to report relieving ΔP; back-pressure correction factor Kb is assumed 1.0 (conventional valve, low back pressure) — verify against your valve type.

Vapor/Gas Relief Rate

~29 for air; use the relieving fluid's actual molecular weight.
1.4 for diatomic gases (air, N₂); ~1.3 for CO₂/steam; ~1.1-1.2 for heavier hydrocarbons.
0.975 is the API 520 default for preliminary sizing before a specific valve is selected.
2

Liquid Relief Rate

0.65 is the API 520 default certified liquid Kd for preliminary sizing.
1.0 for low-viscosity fluids (Reynolds number above the correction threshold); reduce for viscous service.

How this is calculated
—
P1 = set pressure × (1 + overpressure%) + 14.7 psia. Vapor: C = 520·√(k·(2/(k+1))^((k+1)/(k−1))); A = W / (C·Kd·P1·Kb) · √(TZ/M), T in °R. Liquid: A = Q / (38·Kd·Kv) · √(SG/(P1−P2)). These are the API 520 preliminary sizing equations — the standard orifice designations (D through T) are the closest API 526 letter at or above the calculated area, not a final valve selection.
Preliminary sizing only — fire case heat input, two-phase/flashing relief, and a manufacturer-certified Kd all need the full API 520/521 method. ← Process Index
