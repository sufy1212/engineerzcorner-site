Nothing is saved between visits — generate and copy the list before closing the tab.

How this is calculated
Cards needed (per type) = ceil(point count ÷ points per card)
This is a planning-stage point count, not a final I/O architecture — it doesn't account for spare/spartial capacity philosophy, redundant I/O, HART multiplexing, safety-rated (SIL) I/O kept on separate cards from standard I/O, or a specific vendor's actual card point density. Use it to size a rough card count early, then confirm against the selected platform's real module specifications.
