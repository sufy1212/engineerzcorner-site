A simplified sigma-index screening check for liquid control valve service — flags whether a valve is likely operating clean, near incipient cavitation, cavitating, or flashing. The valve's actual incipient-cavitation sigma (σᵢ) is trim- and manufacturer-specific; the default below is a typical standard-trim globe valve value — use the manufacturer's actual figure for a final check.

How this is calculated
—
σ = (P1 − Pv) / (P1 − P2). Flashing occurs when P2 ≤ Pv (downstream pressure never recovers above vapor pressure). Cavitation risk rises as σ approaches or falls below the valve's incipient-cavitation sigma σᵢ — a comfortable margin is generally σ ≥ 1.5·σᵢ.
Screening check only — trim-specific σᵢ, σc (choked) and manufacturer sizing software give a definitive answer for a specific valve. ← Process Index
