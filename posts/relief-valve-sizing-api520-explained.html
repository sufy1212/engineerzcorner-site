Relief Valve Orifice Sizing

The orifice area formula is only ever as good as the relieving rate fed into it — and that number comes from whichever overpressure scenario actually governs, not from the formula itself.

Set pressure and relieving pressure aren't the same number

A relief valve's set pressure is where it's adjusted to begin opening — the value stamped on the valve and checked at test bench. But the pressure the valve actually has to handle at full capacity, the relieving pressure, is higher: set pressure plus an allowable overpressure. That margin exists because a spring-loaded valve doesn't snap instantly from closed to fully open at set pressure — it needs a bit of extra pressure rise to lift fully and pass rated flow. Code allows 10% overpressure for a single valve on non-fire service, 16% where multiple valves are installed, and typically 21% for a fire-case scenario — three different numbers for what's conceptually the same margin, because the applicable code case changes with the situation.

1Set Pressure & Overpressure

  • Relieving pressure = set pressure × (1 + allowable overpressure %), plus atmospheric pressure if working in gauge units
  • The allowable overpressure percentage is fixed by code for the applicable case — it isn't a value chosen freely to make the sizing come out favorably
  • Set pressure itself is normally required to sit at or below the equipment's MAWP, not chosen independently of it

2Back Pressure

  • Superimposed back pressure: already present in the discharge system before the valve opens, from a common header or downstream equipment
  • Built-up back pressure: generated by the valve's own flow through the discharge piping as it relieves
  • High or variable back pressure limits conventional PSVs and often pushes the selection toward balanced-bellows or pilot-operated designs, which tolerate it far better

3Required Relieving Rate

  • Comes from whichever overpressure scenario governs for that equipment — blocked outlet, external fire, control valve failure, tube rupture, and others each give a different rate
  • Sizing the orifice always uses the largest (governing) rate among all applicable scenarios, not an average or a typical one
  • Determining this rate is its own separate engineering study — the orifice sizing formula has no way to check whether the number fed into it is actually the right one

4Orifice Area & Standard Sizes

  • The calculated required area is a continuous number; actual valves are manufactured in a fixed catalog of standard API letter-designated orifices (D through T)
  • The result is always rounded up to the next standard size at or above the calculated requirement — never down, and never built to the exact calculated area
  • A calculated area landing just above a standard size still requires the next size up — there's no partial-size option

The formulas

A (vapor/gas)  =  W  /  (C × Kd × P1 × Kb × Kc)  ×  √(T × Z / M)
W is the required relieving rate (mass flow); P1 is relieving pressure (absolute); Kd is the discharge coefficient; Kb corrects for back pressure; Kc corrects for a rupture disc in combination, where applicable.
A (liquid)  =  Q  /  (38 × Kd × Kw × Kc × Kv)  ×  √(SG / (P1 − P2))
Q is the required relieving rate (volumetric); Kw corrects for back pressure on a balanced-bellows valve; Kv corrects for viscosity at low Reynolds numbers — both formulas share the same shape: rate divided by a set of correction-factor-adjusted constants, scaled by a pressure or property term under a square root.

Working through the sizing

1Identify the governing overpressure scenario (blocked outlet, fire, control valve failure, etc.) and obtain the required relieving rate from that study.
2Set the valve's set pressure at or below equipment MAWP, and determine the allowable overpressure % for the governing case.
3Calculate relieving pressure: set pressure × (1 + overpressure %), converted to absolute.
4Determine superimposed and built-up back pressure, and select a valve type (conventional, balanced-bellows, or pilot-operated) that tolerates it.
5Calculate required orifice area using the API 520 vapor or liquid formula, with the appropriate correction factors.
6Round up to the next standard API letter-designated orifice size at or above the calculated area.

Common terms, decoded

TermMeaning
Set pressureThe pressure at which a relief valve is adjusted to begin opening
OverpressureThe allowable pressure rise above set pressure needed for the valve to reach full rated flow
Relieving pressureSet pressure plus allowable overpressure — the pressure the orifice sizing calculation is actually based on

What each factor is sensitive to

Back-Pressure Dependent
Fluid-Property Dependent

Molecular weight and specific heat ratio (vapor) or specific gravity and viscosity (liquid) all feed directly into the sizing formula — a relief scenario that changes the relieving fluid's composition, such as a two-phase or changing-composition fire case, needs the property values re-evaluated for that specific case rather than reused from the original design basis.

Key takeaways

  • ✓Relieving pressure is set pressure plus allowable overpressure, not set pressure alone — and the overpressure percentage is fixed by the applicable code case.
  • ✓Superimposed and built-up back pressure are two different things, and high or variable back pressure pushes valve selection toward balanced-bellows or pilot-operated types.
  • ✓The required relieving rate comes from a separate overpressure-scenario study — the orifice formula can't validate whether that input is correct.
  • ✓Calculated orifice area always rounds up to the next standard API letter-designated size, never down and never to an exact custom size.
  • ✓Fluid properties (molecular weight, specific gravity, viscosity) feed directly into the sizing formula and need re-checking whenever the governing scenario changes the relieving fluid.
