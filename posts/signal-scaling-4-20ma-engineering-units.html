Signal Scaling: Turning a 4–20mA Loop Into an Engineering Value

A transmitter doesn't send "level" or "pressure" down the wire — it sends a current between 4 and 20mA. Scaling is the step that turns that raw number back into something an operator can read.

A 4–20mA transmitter output is a raw current, not the process variable itself — scaling maps that current onto a real engineering range.

The relationship between current and process value is linear, so a single straight-line formula converts between them in either direction.

4mA represents the transmitter's zero (lower range value, LRV), not zero current failure — a true wire break or dead loop shows up below 4mA.

Getting the LRV/URV entered into the PLC or DCS wrong is one of the most common — and hardest to notice — instrumentation errors on a live loop.

Why 4mA, not 0mA

A 4–20mA loop deliberately starts at 4mA rather than 0mA so that the system can tell the difference between "the process variable is at its minimum" and "the loop is dead." If the measured current drops to zero or goes negative, that's a wiring fault, a blown fuse, or a disconnected transmitter — not a valid reading of zero level, zero pressure, or zero flow. This is often called live-zero.

The linear scaling formula

PV = LRV + (mA − 4) ÷ 16 × (URV − LRV)
PV = process value in engineering units · LRV = lower range value (value at 4mA) · URV = upper range value (value at 20mA) · 16 = the span of the current signal itself (20 − 4)

Every term in this formula comes straight from the transmitter's datasheet or calibration record: LRV and URV define what the transmitter is actually ranged for, and the current is whatever the input card measures. Get any one of those wrong in the PLC configuration and every reading downstream is wrong by the same proportional error — often without tripping any alarm, because the value still looks plausible.

Worked example

A level transmitter is ranged 0–5m (LRV = 0, URV = 5) and currently reads 12mA.

PV = 0 + (12 − 4) ÷ 16 × (5 − 0) = 2.5 m
12mA sits exactly halfway between 4 and 20mA, so the scaled level lands exactly halfway between 0 and 5m — confirming the linear relationship

Two directions, two formulas

mA → engineering unitsUsed on the input side, in the PLC/DCS/RTU, to turn a raw current reading into a displayed process value for operators and control logic.
Engineering units → mAUsed on the output side, when a controller drives a valve or damper actuator, converting a desired position or setpoint back into a 4–20mA control signal.

Reverse formula (engineering value to current)

mA = 4 + (PV − LRV) ÷ (URV − LRV) × 16
Same relationship, solved the other way — this is what drives an output card sending a signal to a control valve or VFD

Where scaling errors actually come from

  • 1LRV/URV entered in the PLC don't match the transmitter's actual configured range — a re-ranged transmitter whose PLC tag was never updated.
  • 2Units mismatch — transmitter ranged in bar while the PLC tag assumes kPa, or metres vs. millimetres.
  • 3Reversed range direction — some transmitters can be configured so 20mA is the lower physical value (e.g. reverse-acting level), which flips the formula's sign.
  • 4Input card scaling set in raw counts (e.g. 0–27648 for a 12-bit card) instead of milliamps, doubling up a conversion that's already handled elsewhere.
  • 5Damping/filtering applied at both the transmitter and the PLC, which doesn't break scaling but can make a genuine fast transient look like measurement noise.

Sanity-checking a scaled reading

Current% of spanExpected condition
< 3.6mA—Loop fault / broken wire (below live-zero)
4.0mA0%Process variable at LRV
12.0mA50%Process variable at midpoint of range
20.0mA100%Process variable at URV
> 20.5mA—Over-range / transmitter saturation or fault

Key takeaways

  • ✓4mA is a live zero, not "nothing" — a reading below it means a loop fault, not a valid low process value.
  • ✓Scaling is linear: PV = LRV + (mA−4)/16 × (URV−LRV), and the same relationship runs in reverse for analog outputs.
  • ✓LRV and URV must match the transmitter's actual configured range exactly — a mismatch produces a plausible-looking but wrong reading.
  • ✓4–20mA at 0% and 100% and a quick 12mA midpoint check are enough to sanity-verify most scaled loops on commissioning.
