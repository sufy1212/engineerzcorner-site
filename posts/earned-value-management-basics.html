Earned Value Management: Reading Project Health From Three Numbers

"We're on budget" and "we're on schedule" are two completely different claims. Earned Value Management is the discipline of never confusing the two.

Engineerz CorneRReference · Project Management
01
EVM tracks three numbers at once: what was planned, what's actually been completed, and what it cost.
02
A project can be under budget and still badly behind schedule, or vice versa.
03
CPI and SPI turn those three numbers into a single ratio each — below 1.0 is a warning sign.
04
These indices work early, while there's still time to correct course.

The three inputs

Every EVM calculation starts from three figures, all expressed in the same currency so they're directly comparable:

PV — Planned ValueThe budgeted cost of the work that was scheduled to be done by this point in the project.
EV — Earned ValueThe budgeted cost of the work actually completed so far — not what was spent, what was finished.
AC — Actual CostWhat has genuinely been spent to get that work done, regardless of budget.

The reason all three are needed is that cost and schedule can drift independently. Spending exactly as planned (AC = PV) tells you nothing about whether the matching amount of work actually got finished — that's what EV is for.

Turning that into two ratios

CPICost Performance Index
=
EVearned value
÷
ACactual cost
SPISchedule Performance Index
=
EVearned value
÷
PVplanned value
Both are ratios centred on 1.0: above 1.0 is favourable, below 1.0 means less value was earned than the money spent (CPI) or the time scheduled (SPI) would suggest.

Reading the result

ResultWhat it means
CPI > 1.0Getting more value than what's being spent — under budget
CPI < 1.0Spending more than the value being earned — over budget
SPI > 1.0Ahead of the planned schedule
SPI < 1.0Behind the planned schedule
CPI < 1.0 and SPI < 1.0Over budget and behind schedule at once — the combination that needs attention fastest

Worked example

A project has, by this reporting point, planned $100,000 of work (PV), actually completed $80,000 worth of that work (EV), and spent $95,000 getting there (AC).

Result

CPI = EV / AC80,000 / 95,000 = 0.84
SPI = EV / PV80,000 / 100,000 = 0.80
ReadingOver budget and behind schedule

Both index below 1.0 at once is the clearest possible early flag: the team is spending more than the completed work is worth, while also completing less than what was scheduled by this point — two separate problems showing up in the same report.

Key takeaways

  • ✓Cost performance and schedule performance are separate questions — check both, not just one.
  • ✓Earned Value means work actually completed, not money actually spent — the two are easy to conflate.
  • ✓CPI and SPI below 1.0 are early warnings, useful precisely because they surface before the project is visibly in trouble.
  • ✓Track both indices over time, not as a single snapshot — the trend matters as much as the current value.
