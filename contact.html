What to write in about

Corrections: found a formula, unit, or reference value that looks off in a calculator or post? Include the page URL and what looks wrong — these get prioritized.

Feature requests: a calculator or reference page you'd find useful that isn't here yet.

General feedback: anything about how the site works, reads, or could be more useful.

Before you write

A few details make it much faster to act on a message: the exact page URL, the input values you used if a calculator gave an unexpected result, and — for a suspected error — the code, standard, or reference you're checking against. A screenshot helps too if the issue is visual rather than numerical.

If you've spotted the same issue on more than one page (a unit label, a rounding behavior, a broken link), one message listing all of them is easier to track than several separate ones.

Response time

This is a one-person, independent project run alongside other work, so replies aren't instant — but every message is read.
