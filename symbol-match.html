About Symbol Match

Every icon in this game comes straight from Engineerz CorneR's own per-discipline symbol libraries — the same Automation, Process, Mechanical, HVAC, Civil and Solar reference pages you'd use to look a symbol up. This game just turns recognizing them into something faster to practice.

Pick a single discipline to drill it in isolation, or Mixed to pull a random spread across all six — useful once individual sets start feeling too easy. Time and moves are tracked per set, with your best kept locally in this browser.
