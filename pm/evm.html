How this is calculated
CPI = EV/AC  ·  SPI = EV/PV  ·  CV = EV−AC  ·  SV = EV−PV
EAC = BAC/CPI  ·  ETC = EAC−AC  ·  VAC = BAC−EAC  ·  % Complete = EV/BAC
EAC here uses the common "CPI-based" formula, which assumes current cost performance continues for the remaining work — one of several EAC methods in practice; use a different one if your project's remaining work is expected to perform differently than it has so far.
