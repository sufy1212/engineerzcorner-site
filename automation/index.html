Automation — Calculator Index

Fig. A1 — Sensor, controller and valve, closing one loop
Twelve standalone controls/instrumentation calculators, a learning-notes reference page, a click-to-explore P&ID symbol library, step-by-step engineering guides, and head-to-head comparisons — pick one below. Like Mechanical and HVAC, these aren't chained together, so each one is self-contained.

AT.01
Signal Scaling
Convert a 4-20mA / 0-10V / 0-20mA / 1-5V analog signal to engineering units, and back — for range-checking transmitters and PLC analog inputs.
AT.02
PID Tuning (Reaction Curve)
Starting P, PI or PID gains from an open-loop step-test model (process gain, time constant, dead time), via the Ziegler-Nichols reaction-curve method.
AT.03
Control Valve Sizing (Cv/Kv)
Flow coefficient (Kv and Cv) for a control valve from flow rate, pressure drop and fluid specific gravity.
AT.04
DP Level Transmitter Ranging
Hydrostatic pressure span for a differential-pressure level transmitter from fluid density and tank level span, with the matching 4-20mA calibration points.
AT.05
VFD Frequency / Speed Scaling
Motor speed at a given drive output frequency from the nameplate rated speed and frequency, for quick VFD commissioning checks.
AT.06
Learning Notes
Reference-only theory notes on control loops, instrumentation, PLC logic, networks, final control elements, safety interlocks and standards — not a calculator.
AT.07
Symbol Library
Click-to-explore reference of common P&ID and instrumentation symbols — instrument bubbles, field devices, valves, signal lines, panels and safety elements.
AT.08
Engineering Guides
Ten step-by-step how-to guides — PID tuning, DP level ranging, control valve sizing, reading a P&ID, VFD commissioning, loop troubleshooting and more.
AT.09
Comparisons
Eight head-to-head comparisons — 4-20mA vs 0-10V vs HART, PLC vs DCS vs SCADA, PID vs on-off control, and more.
AT.10
Deadband / Hysteresis
Switch-on/switch-off trip points from a setpoint and deadband width, expressed in engineering units and %FS.
AT.11
RTD (Pt100) Conversion
Temperature ↔ resistance for a standard Pt100 RTD using the IEC 60751 Callendar-Van Dusen equation, both directions.
AT.12
Relay/Contactor Coil Sizing
Coil current and power from voltage/resistance, plus duty cycle and average power from on-time and cycle period.
AT.13
Modbus RTU Timing
Character time, inter-character (t1.5) and inter-frame (t3.5) silent intervals, and frame transmit time from baud rate and message length.
AT.14
Alarm Setpoint Bands
High/High-High and Low/Low-Low trip and reset points from %FS positions and a reset deadband.
AT.15
Thermocouple Reference
Type K mV ↔ temperature per NIST ITS-90, plus cold-junction compensation for a measured terminal-block reading.
AT.16
Orifice Flow Sizing
DP flow element sizing — flow rate from bore and differential pressure, or required bore for a target flow and ΔP.
