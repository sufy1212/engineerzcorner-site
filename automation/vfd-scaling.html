How this is calculated
Nsync = 120·f/poles  ·  sliprated = Nsync,rated − Nrated  ·  Ntarget ≈ Nsync,target − sliprated
Holds slip constant in RPM rather than recalculating it from load and torque — a reasonable approximation for constant-torque loads in normal V/Hz operation below base speed. Above base speed (field weakening) or for closed-loop vector drives, use the drive's actual speed feedback instead.
Commissioning estimate — confirm actual running speed against a tachometer or the drive's speed feedback display.
