How this is calculated
E₀-ref = E_measured + E(T_cold junction)  ·  T_hot = E⁻¹(E₀-ref)
A thermocouple only measures the temperature difference between its two junctions, not an absolute value. A bare thermocouple's leads are themselves a second, unwanted thermocouple junction wherever they land on a terminal block — so the raw mV reading is actually the EMF for (hot junction temperature − terminal block temperature), not (hot junction − 0°C). Adding back the EMF the terminal block temperature would itself generate against a 0°C reference recovers the equivalent 0°C-referenced EMF, which then converts to the true hot-junction temperature using the same Step 2 curve. This is exactly what a transmitter's built-in cold-junction sensor (usually an RTD or IC sensor right at the terminals) does automatically — this calculator does it manually for a check, a legacy analog display, or a DIY DAQ input with no CJC of its own.
