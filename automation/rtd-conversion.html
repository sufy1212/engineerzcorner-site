How this is calculated
T≥0°C: R = R₀(1 + AT + BT²)  ·  T<0°C: R = R₀(1 + AT + BT² + C(T−100)T³)
R₀ = 100Ω, A = 3.9083×10⁻³, B = −5.775×10⁻⁷, C = −4.183×10⁻¹²
Resistance→temperature is solved numerically (Newton-Raphson) against the same equation, so both directions stay consistent. This is the standard curve — a real RTD's tolerance class (A/B/AA per IEC 60751) adds an additional ± error band on top.
IEC 60751 standard Pt100 curve (α = 0.00385) — not for RTD types with a different alpha (e.g. Pt100 α = 0.003916 to old JIS/DIN variants) without adjusting the coefficients.
