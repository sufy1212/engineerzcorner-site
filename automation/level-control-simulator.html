How this is calculated
Each simulation tick: error = setpoint − level, and a standard PID computes valve output u = Kp·error + Ki·∫error·dt + Kd·d(error)/dt, clamped to 0–100% and applied as the inlet valve position (with a simple first-order valve-travel lag, so it doesn't snap open/closed instantly).
Tank level changes by Δlevel = (inflow − outflow)·dt, with inflow proportional to the inlet valve position and outflow proportional to the outlet valve position (baseline demand, or the kicked value while a disturbance is active) — a fixed reference tank size, tuned so the response speed feels realistic on screen.
Kick Disturbance steps the outlet valve open by the kick size for a fixed duration, then returns it to baseline — a classic load-disturbance rejection test.
HH/LL lamps light the instant level crosses the entered alarm bands; the status banner turns red on either trip.
