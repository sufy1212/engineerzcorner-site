How this is calculated
1oo1: λDU·TI/2  ·  2oo2: λDU·TI
1oo2: [(1−β)λDU·TI]²/3 + βλDU·TI/2
2oo3: [(1−β)λDU·TI]² + βλDU·TI/2
Total PFDavg = sensor + logic solver + final element
Low-demand bands (IEC 61508): SIL 1 = PFDavg ≥10⁻² to <10⁻¹, SIL 2 = ≥10⁻³ to <10⁻², SIL 3 = ≥10⁻⁴ to <10⁻³, SIL 4 = ≥10⁻⁵ to <10⁻⁴. Architectural limit comes from the Route 1H table (IEC 61508-2) using element type, SFF and the HFT implied by the voting (1oo1 and 2oo2 = 0, 1oo2 and 2oo3 = 1). This tool does not model repair time, diagnostics-driven partial stroke tests, imperfect proof tests, high-demand/continuous mode (PFH), systematic capability or the safety lifecycle, and the simplified equations lose accuracy when λDU·TI is not much smaller than 1. Use certified failure data from each device’s safety manual, and a qualified functional safety engineer for the final verification.
Screening estimate for a low-demand safety instrumented function. A SIL claim also needs systematic capability, lifecycle compliance and documented verification under IEC 61508/61511.
