How this is calculated
Bits/char = 1 start + 8 data + parity bit(s) + stop bit(s)
Char time = bits / baud
≤19200 baud: t1.5 = 1.5×char time, t3.5 = 3.5×char time
>19200 baud (per spec addendum): t1.5 fixed at 750µs, t3.5 fixed at 1750µs
A gap exceeding t1.5 between characters is treated as a framing error by RTU receivers; a gap exceeding t3.5 marks the end of a frame. Many real UART/USB-serial adapters can't hold to these tightly at low baud rates — some master/slave stacks use a fixed ~3.5–5ms minimum instead.
Modbus RTU spec (Modbus.org, Modbus Serial Line Protocol) — timing intervals for standard 8-N-2 / 8-E-1 / 8-O-1 framing.
