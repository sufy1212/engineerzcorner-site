How this is calculated
Q = Cd · (π/4)·d² · √( 2ΔP / (ρ·(1−β⁴)) )  ·  β = d/D
This uses the standard square-edge orifice equation with the velocity-of-approach (1−β⁴) correction, expansibility factor ε taken as 1 (valid for liquids; gas/steam service needs an ε correction below about 1, which this sheet doesn't apply). Bore sizing solves the same equation iteratively for d. In practice β is normally kept between about 0.2 and 0.75 for accurate, well-characterized measurement — outside that range, discharge coefficient and uncertainty depart from the simple constant-Cd assumption used here, and a full standard (ISO 5167, AGA-3) calculation with Reynolds-number-dependent Cd is needed.
Simplified square-edge (thin-plate, flange- or corner-tap) orifice equation, constant Cd assumption — for preliminary sizing and field checks only.
