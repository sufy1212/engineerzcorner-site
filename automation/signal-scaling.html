How this is calculated
EU = EUlo + (raw − rawlo)/(rawhi − rawlo) · (EUhi − EUlo)  ·  and the same relationship solved in reverse for raw from EU.
Straight linear scaling — for a square-root-extracted signal (e.g. some legacy DP flow transmitters) or a signal with live-zero suppression, apply that characterization before or after this scaling.
Assumes linear 4-20mA-style analog scaling — check the transmitter/PLC channel configuration for any non-linear characterization.
