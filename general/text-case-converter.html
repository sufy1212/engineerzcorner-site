When Each Case Style Is Used

UPPERCASE and Title Case are common in headings, safety labels and drawing titles; Sentence case reads most naturally in prose and reports. The remaining five — camelCase, PascalCase, snake_case, kebab-case and CONSTANT_CASE — are naming conventions from software and PLC/tag programming: camelCase and PascalCase are typical for variable and class names, snake_case shows up in database columns and Python code, kebab-case is standard for URLs and file names, and CONSTANT_CASE is the usual style for constants and #define values.

Word boundaries are detected from spaces, punctuation, underscores/hyphens, and camelCase transitions (so pasting an existing camelCase or snake_case string re-splits correctly before rebuilding it in the other styles). Numbers are treated as part of the surrounding word.

Runs entirely client-side — nothing you type is sent over the network.
