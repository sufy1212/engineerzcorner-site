Engineering Sanity-Checker

Catch the unit slip before it catches you — checks a value against typical real-world ranges
Pick a quantity type, enter your value and unit — it flags whether the number is a plausible order of magnitude for that context, and if not, checks whether a common unit mix-up (kN↔N, MPa↔kPa, bar↔psi, etc.) would explain it. A judgement aid, not a calculation check — it can't know your specific case, only whether the number is in a normal ballpark.

Typical ranges are broad, real-world rules of thumb for common cases — not a design code limit. Unusual but valid designs exist outside these bands; use engineering judgement and the applicable code for anything that matters.
