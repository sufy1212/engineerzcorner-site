What Makes a Password Strong

Length matters more than complexity once you're past a reasonable minimum — combining character sets (uppercase, lowercase, numbers, symbols) does increase the number of possible combinations, but a longer password is generally harder to crack than a short, convoluted one. This tool builds each password using the browser's crypto.getRandomValues API, a cryptographically secure random source, rather than the weaker Math.random() some sites still rely on for this kind of thing.

Nothing here touches a network. Generation happens entirely in your browser, so no request is sent anywhere and this tool never logs or stores a generated password. Save it straight into a password manager, and use a unique password per account — that way a single breached site can't be used to unlock your other accounts.
